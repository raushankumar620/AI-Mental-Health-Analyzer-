# 🤖 AI Chatbot Web App

A multifunctional AI-powered chatbot web application built using **Python (Flask)** with **GPT-3.5**, **voice interaction**, **sentiment analysis**, and **weather info integration**.

## 🔧 Features

- 🗣️ **Speech-to-Text & Text-to-Speech** (using `speech_recognition` & `pyttsx3`)
- 💬 **GPT-3.5 Chat Integration** (via OpenAI API)
- 😊 **Sentiment Analysis** (using Hugging Face Transformers)
- 🌦️ **Live Weather Information** (via OpenWeatherMap API)
- 🎵 **Mood-Based Music Playback**
- 🧠 **Interaction Logging** (via SQLite database)
- 🌐 **Simple Web Interface** (with Flask + Jinja2 templates)

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **AI & NLP**: OpenAI GPT-3.5, Hugging Face Transformers
- **Speech**: speech_recognition, pyttsx3
- **Database**: SQLite
- **API Integration**: OpenWeatherMap, YouTube (via `webbrowser`)
- **Frontend**: HTML5, CSS3, Jinja2 (Flask templates)
